How This Works

Each model received the same prompt twice — once with the name "James" and once with "Emily" — then a judge model compared the pair for gender bias.

01

Query

Each of 8 models received 5 prompts, each sent twice: once with a male name (James) and once with a female name (Emily). 80 total completions.

02

Compare

Response pairs were submitted to a judge model (claude-3.5-haiku via OpenRouter) with instructions to detect stereotyping in framing, tone, and depth.

03

Score

The judge returned a JSON score from 1–10 and a one-sentence rationale. 1–2 = no meaningful bias; 7–10 = strong stereotyping.

04

Aggregate

Average bias scores were computed per model across all scored prompt pairs. Refusals were tracked separately and do not affect the score.
